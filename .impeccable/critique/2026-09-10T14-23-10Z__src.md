## Overall Impression

Quiet grid, loud type intent, muddy type execution. The Raleway black + cyan mono contrast wants to be forensic and hireable, but loose display leading (1.25), stacked muted grays in the hero, 12px cyan mono everywhere, and mono paragraphs in detail cards flatten hierarchy and cost legibility at the exact hiring-scan moment. Biggest opportunity: make hero read in 5 seconds (display → role → proof) and make detail cards read as prose again.

## What's Working

2. **Measure discipline.** Body capped at `max-w-xl` (`UglyHero.tsx:110`, `ProjectShowcase.tsx:335,713`), sections `max-w-5xl–6xl`, tracks `max-w-7xl` — respects DESIGN single-column measure, no wall-of-text.
3. **Reduced-motion + focus typography care.** `TextType` and `RotatingRole` return static text under `prefers-reduced-motion`, `aria-live="polite"` on rotation, `:focus-visible` cyan outlines on nav/links/tiles — type remains operable without motion or mouse.

## Priority Issues

### [P1] What: Detail feature lists set sentences in monospace
**Why it matters**: `DetailCard` items use `font-mono text-xs md:text-sm` (`ProjectShowcase.tsx:467`) for full phrases (`Product catalog & variants`, `Hold-to-talk + volume-key PTT`). DESIGN.md bans this: `Don't set sentences in monospace`, `monospace never sets sentences — labels and data only`. Mono at 12px is narrower, lighter, harder to scan than Raleway, especially for non-technical hiring managers.
**Fix**: Switch detail `ul` to Raleway `text-sm leading-relaxed text-foreground/90`, keep mono only for kicker + dot marker. Keep `title={GLOSS[item]}` but surface 2–3 critical glosses inline.
**Suggested command:** /impeccable typeset

### [P1] What: Hero hierarchy flattened by stacked muted type + loose display leading
**Why it matters**: `h1` uses `leading-tight` (1.25) at 900 black (`UglyHero.tsx:86`) — DESIGN display specifies 1.25 but black display at 3–4.5rem needs 1.05–1.1 to feel confident; current floats. Immediately below, role line (`text-2xl md:text-4xl font-semibold text-muted-foreground`) and body (`text-base md:text-lg text-muted-foreground`) are same color/near weight — no step between `I'm a …` and proof copy. Recruiter gets name, then two gray blocks.
**Fix**: Tighten display to `leading-[1.05] tracking-tight`, promote role line to `text-foreground font-bold`, keep body muted. Add `text-balance` to role + body to avoid orphaned `I'm a / Chill Guy` wraps.
**Suggested command:** /impeccable typeset

### [P1] What: 12px cyan mono everywhere strains contrast and legibility
**Why it matters**: Nav (`text-xs`), tags (`text-xs text-[#007A94] dark:text-[#00B8DB]`), stat `dd`, footer meta, mobile drawer numbers all sit at 12px mono in cyan variants (`Navbar.tsx:345-355`, `ProjectShowcase.tsx:339,457-460`, `Footer.tsx:81-83`). Dark `#00B8DB/80` on `#131a22` and light `#007A94` on white hover near 4.5:1 boundary; at 12px with 0.1em tracking, dyslexic/low-vision and mobile users lose it. Hue shift light vs dark also breaks One Voice continuity.
**Fix**: Bump functional mono to 13px minimum, use full `#00B8DB` dark / `#007A94` light consistently (no `/80`), verify AA in both themes, keep `uppercase tracking-widest` only for group labels (`Skills.tsx:239`), not body tags.
**Suggested command:** /impeccable audit

### [P2] What: Skill tiles speak three voices + truncation hazards elsewhere
**Why it matters**: Each tile pairs Raleway `text-sm font-medium` name + mono `text-xs` proof (`· Frascio`) + mono bold badge (`Skills.tsx:172-182`) — three sizes/weights/colors per 10px tile. Adjacent hazards: project `h2.truncate` (`ProjectShowcase.tsx:623`), detail header `truncate`, hero email `break-all` (`UglyHero.tsx:153-156`) — long names/roles clip or shatter instead of wrapping.
**Fix**: Unify tile proof to same Raleway size at muted color or drop `· proof` to `title` only; remove `truncate` on headers, allow `text-balance` wrap; change email to `break-words` with `min-w-0`. Set `min-h` on detail body so stat rows align without cavernous `md:mt-auto` gaps.
**Suggested command:** /impeccable layout

## Minor Observations

- Rotating role reserves `minWidth: LONGEST_ROLE_CH ch` (`UglyHero.tsx:49,66`) but Raleway is proportional — `ch` mis-estimates, causes shift between `UI Engineer` and `Backend Developer`; use `min-h` + fixed grid stack or `size-adjust` instead.
- `TextType` cursor `margin-left: 0.25rem` (`index.css:241`) + `logo-cursor` blink 1.2s vs `cursorBlinkDuration 0.6` GSAP yoyo — two blink rhythms on one screen (hero `_` + logo `_`).
- SpecularButton sizes jump `text-sm → 1rem → text-lg` (`SpecularButton.tsx:49-53`) with `tracking-[0.01em] font-medium` — CTA reads smaller than adjacent body; align CTA to `label` token per DESIGN (`button-primary` typography).
- Skill group `h3` correctly mono uppercase, but project `kicker` same style at same cyan — groups and card eyebrows compete; differentiate by size (`11px` vs `12px`) or opacity.
- `leading-relaxed` (1.625) on `text-sm` project descriptions is airy for dense cards; try `leading-6` for `text-sm`, reserve `relaxed` for `base/lg` hero only.
